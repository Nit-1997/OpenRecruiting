# setup-ui Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax.

**Goal:** `docker compose up -d` → open `http://127.0.0.1:3010` → set a password → fill in what you have → Save & Apply → use the product. No hand-editing `.env` before the first successful boot.

**Architecture:** A dependency-free FastAPI service that owns `.env` and `litellm-config.yaml` as *files* (they stay hand-editable), applies Supabase's schema, and restarts only the containers a change affects — through a scope-restricted Docker socket proxy, never the raw socket. Bound to `127.0.0.1`.

**Tech Stack:** Python 3.11, FastAPI, httpx, PyYAML, passlib[bcrypt], pytest. Vanilla HTML/CSS/JS frontend (no build step — a setup tool must not need one).

**Source spec:** `docs/superpowers/specs/2026-08-11-self-host-settings-ui-design.md`
**Prerequisite:** `docs/superpowers/plans/2026-08-11-runtime-frontend-config.md` — **COMPLETE**. Without it, saving a Supabase URL could not reach the browser.

## Global Constraints

- **Every HTML element must carry a unique `id`** (project-wide rule, `CLAUDE.md`).
- **Never commit secrets.** `.env`, `*.bak.*`, and the password hash file are gitignored.
- **Only public values may be sent to the browser.** Secrets are write-only: the API returns `{"set": true}`, never the value.
- **Bind `127.0.0.1` only.** Never `0.0.0.0` by default.
- **Never mount the raw Docker socket into `setup-ui`.** Only the proxy may see it.
- Commit per task, self-review (`git diff --cached`) first.
- Baselines: backend `make test` **2193 passed / 5 skipped**; recruiter-app **1278 pass / 2 known-flaky**; landing **32 passed**; `make verify` all ten ok.

## Definition of done

- `docker compose up -d` on a fresh checkout: `setup-ui` reachable, other services boot degraded rather than crash-looping.
- Setting a password, saving Supabase creds, applying the schema, and adding a provider key all work from the browser.
- Secrets never appear in a response body.
- `.env` keeps its comments and key order after a save.
- Only mapped containers restart.
- `setup-ui` cannot create containers or exec — proven by calling the proxy directly and getting refused.
- Existing suites unchanged: backend 2193/5, recruiter-app 1278/2, landing 32, `make verify` ten ok.
